## 1. Что именно реализовано

Консольное приложение оценивает (методом Монте-Карло) математическое ожидание и дисперсию для:

- `A` — сумма весов рёбер минимального остовного дерева связного графа на `n` вершинах;
- `B` — длина самого большого (по числу рёбер) цикла;
- `D` — число рёбер цикла с максимальной суммой весов;
- `E` — количество изолированных вершин;
- `F` — количество деревьев (с точностью до перестановки вершин), то есть число неизоморфных деревьев;
- `G` — количество компонент связности;
- `H` — количество компонент связности, являющихся полными подграфами (кликами).

---

## 2. Какую вероятностную модель использует программа

Так как в условии не задана конкретная модель случайного графа, принято:

1. Для `A, B, D`:
   - генерируется случайный **связный** взвешенный неориентированный граф;
   - связность гарантируется через случайное остовное дерево;
   - потом добавляются дополнительные рёбра с вероятностью `p_weighted`;
   - вес каждого ребра: целое число от `1` до `10`.

2. Для `E, G, H`:
   - генерируется граф Эрдёша-Реньи `G(n, p_unweighted)`.

3. Для `F`:
   - используется табличное число неизоморфных деревьев для `n = 1..20`;
   - поэтому при фиксированном `n` дисперсия для `F` равна `0`.

## 6. Запуск программы

Находясь в `build`, запускай так:

```bash
./terver --n 8 --samples 1000 --p-weighted 0.35 --p-unweighted 0.30 --seed 42
```

Параметры:

- `--n` — число вершин (обязательно);
- `--samples` — число прогонов Монте-Карло;
- `--p-weighted` — вероятность доп. ребра в связном взвешенном графе;
- `--p-unweighted` — вероятность ребра в `G(n,p)` для `E,G,H`;
- `--seed` — фиксирует генератор случайных чисел (для воспроизводимых результатов).


---

## 8. Что выводит программа

Программа печатает:

1. параметры запуска;
2. оценки для `A, B, D, E, F, G, H`:
   - `M ~= ...` — приближённое матожидание;
   - `D ~= ...` — приближённая дисперсия.

---

## 9. Набор готовых запусков для отчёта

```bash
./terver --n 6  --samples 5000 --p-weighted 0.30 --p-unweighted 0.30
./terver --n 8  --samples 5000 --p-weighted 0.35 --p-unweighted 0.30
./terver --n 10 --samples 5000 --p-weighted 0.40 --p-unweighted 0.25
./terver --n 12 --samples 5000 --p-weighted 0.45 --p-unweighted 0.20
```

Собери таблицу в отчёт:

- вход: `n`, `samples`, `p_weighted`, `p_unweighted`;
- выход: `M(A), D(A), ..., M(H), D(H)`.

---


## 10. Ограничения

- Для `F` поддерживается `n` от `1` до `20` (таблица в коде).
- Для больших `n` и больших `samples` перебор циклов (`B`, `D`) может работать заметно дольше.
